# Modern Sign-In / Sign-Up Mockup

A sleek, responsive authentication page built with HTML, CSS, JavaScript, and Firebase. It features interactive sliding form transitions, password visibility toggles, local storage fallback for mock accounts, and social authentication via Firebase.

## ✨ Features

- **Animated UI Toggle**: Smooth transition effect switching between Sign In and Sign Up modes.
- **Social Authentication**: Google and GitHub login integration via Firebase Auth.
- **Local Authentication Mock**: Basic email/password registration using browser `localStorage`.
- **Password Visibility Toggle**: Show/hide password utility icons.
- **Responsive Design**: Styled using modern CSS variables, flexbox, and FontAwesome icons.

## 🛠️ Built With

- HTML5 / CSS3 (Montserrat font)
- JavaScript (ES6+)
- Firebase v9 (Compat SDK - Auth & App)
- FontAwesome
